# Work Shift & Wage Calculator (iOS PWA) — v3.0.0

A standalone shift tracker and wage calculator web app designed with native iOS Human Interface aesthetics (Light & Dark Mode). It enables daily shift logging on an interactive visual calendar and calculates total hours and earnings in real time—100% offline.

### 🚀 Key Features (v3.0.0):
- **Native iOS Aesthetic (Dual Mode)**: Clean visual interface featuring squircle date tiles, a 4-column summary grid, and seamless switching between **Light Mode** and **Dark Mode**.
- **Interactive Shift System**:
  - ⚪ **White**: Standard shift (default: 9 hours)
  - 🟡 **Yellow**: Mid shift (default: 7 hours)
  - 🔴 **Red**: Day off (0 hours)
  - 🔵 **Custom**: Flexible shift (default: 3 hours or customizable)
- **Configurable Durations & Rates**: In-app settings sheet to adjust default durations for each shift category as well as the hourly wage rate (default: 130 TL).
- **Instant Automatic Calculations**: Total working hours and estimated wages update immediately on the sticky bottom bar.
- **100% Offline & PWA Ready**: Completely self-contained with no external CDNs or network calls. Fully functional via Safari's *Add to Home Screen* with persistent local caching.
